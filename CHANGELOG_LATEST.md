# formcraft v0.1.0

Local forms, responses, and NPS. Windows x64.

## Downloads

- `formcraft-app.exe`: the desktop window.
- `formcraft.exe`: CLI and MCP server.
- `formcraft-0.1.0-setup.exe`: per-user installer.
- `formcraft-v0.1.0.mcpb`: MCP bundle.

## What is new

- `formcraft serve` listens on 127.0.0.1:14133 and stores responses. The stored address is truncated. A filled honeypot field is discarded.
